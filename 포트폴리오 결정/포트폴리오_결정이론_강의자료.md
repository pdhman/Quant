## 1. 들어가기: 왜 "위험 기반" 배분인가

전통적 **마코위츠 평균-분산 최적화(Mean-Variance Optimization, MVO)** 는 기대수익률 $\mu$와 공분산 $\Sigma$를 모두 입력으로 씁니다.

$$\max_w \; w^T\mu - \frac{\lambda}{2} w^T \Sigma w$$

문제는 **기대수익률 추정 오차가 매우 크다**는 점입니다. 추정 오차는 최적화 과정에서 증폭되어(“error maximization”), 극단적이고 불안정한 비중을 만듭니다.

이에 대한 실무적 대안이 **기대수익률을 쓰지 않고 위험 구조(공분산)만으로 배분**하는 계열입니다. 이 강의의 4개 모델은 정확히 이 스펙트럼을 보여줍니다.

```
정보 사용량 적음 ──────────────────────────────► 많음
 Equal-Weight → Risk Parity → GMV → MDP
 (분산도 안 봄)  (분산·공분산)  (전체 Σ)  (전체 Σ + 개별 변동성)
```

## 2. 기초 개념과 표기

| 기호 | 의미 |
|---|---|
| $n$ | 종목 수 |
| $w = (w_1, \dots, w_n)^T$ | 비중 벡터, $\sum_i w_i = 1$ |
| $\Sigma$ | $n \times n$ 공분산 행렬 |
| $\sigma_i = \sqrt{\Sigma_{ii}}$ | 종목 $i$의 변동성(표준편차) |
| $\sigma_p = \sqrt{w^T \Sigma w}$ | 포트폴리오 변동성 |
| $\rho_{ij}$ | 종목 $i,j$의 상관계수 |

**코드 대응** (`portfolio_optimizer.py`):
- 수익률: `returns = price_data.pct_change().dropna()` (261行)
- 공분산: `cov_matrix = returns.cov()` (93行)
- 포트폴리오 변동성: `np.sqrt(np.dot(w.T, np.dot(cov, w)))`

## 3. 모델 ① Equal-Weight (동일가중)

가장 단순한 벤치마크. 위험조차 보지 않습니다.

$$w_i = \frac{1}{n}$$

**코드**: `portfolios['Equal-Weight'] = np.ones(len(tickers)) / len(tickers)` (120行)

**교육 포인트**: DeMiguel, Garlappi & Uppal(2009)은 "1/N 전략이 많은 정교한 최적화 모델을 아웃퍼폼한다"고 보고했습니다. → **정교함이 항상 우월하지 않다**는 화두를 던지기 좋음.

---

## 4. 모델 ② GMV (Global Minimum Variance)

**아이디어**: 기대수익률을 아예 무시하고, **분산이 가장 작은 포트폴리오**를 찾는다.

### 최적화 문제
$$\min_w \; w^T \Sigma w \quad \text{s.t.} \quad \sum_i w_i = 1,\; l \le w_i \le u$$

### 그래디언트 (해석적)
$$\nabla_w (w^T\Sigma w) = 2\Sigma w$$

**코드 대응** (`get_gmv_weights`, 269~307行):
```python
def objective(weights):
    return np.dot(weights.T, np.dot(cov_array, weights))   # wᵀΣw
def gradient(weights):
    return 2 * np.dot(cov_array, weights)                  # 2Σw
```

### 특징
- 제약이 없을 때 해석해: $w^* = \dfrac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^T \Sigma^{-1}\mathbf{1}}$
- 저변동성·저상관 종목에 비중이 쏠리는 경향 → 집중 위험. 그래서 코드가 상·하한 제약을 둠.

---

## 5. 모델 ③ MDP (Most Diversified Portfolio)

**아이디어**: **분산투자 효과 자체를 극대화**한다 (Choueifaty & Coignard, 2008).

### 분산비율 (Diversification Ratio)
$$DR(w) = \frac{\sum_i w_i \sigma_i}{\sqrt{w^T \Sigma w}} = \frac{\text{(상관관계 무시한) 가중 위험 합}}{\text{(상관관계 반영한) 실제 포트폴리오 위험}}$$

- 분자: 각 종목이 독립일 때의 위험 합
- 분모: 실제 위험 (상관관계로 상쇄됨)
- 상관관계가 낮을수록 $DR$이 커짐 → **DR을 최대화 = 분산효과 최대화**

### 최적화 문제
$$\max_w DR(w) \quad\Longleftrightarrow\quad \min_w \left(-\frac{w^T\sigma}{\sqrt{w^T\Sigma w}}\right)$$

**코드 대응** (`get_mdp_weights`, 309~356行):
```python
vols = np.sqrt(np.diag(cov_array))                         # σ_i
def objective(weights):
    portfolio_vol = np.sqrt(np.dot(weights.T, np.dot(cov_array, weights)))
    return -np.dot(weights, vols) / portfolio_vol          # -DR
```

## 6. 모델 ④ Risk Parity (위험균등)

**아이디어**: **비중이 아니라 위험 기여도를 균등하게** 나눈다.

### 한계위험기여도 (Risk Contribution)
포트폴리오 위험 $\sigma_p$는 오일러 분해로 각 종목 기여도의 합으로 나뉩니다:

$$\sigma_p = \sum_i RC_i, \qquad RC_i = w_i \cdot \frac{\partial \sigma_p}{\partial w_i} = \frac{w_i \,(\Sigma w)_i}{\sigma_p}$$

### 목표
모든 종목의 위험 기여도를 동일하게:
$$RC_i = \frac{\sigma_p}{n} \quad\text{(정규화 기준 } RC_i / \sigma_p = 1/n)$$

### 최적화 문제 (코드 구현 형태)
$$\min_w \sum_i \left( \frac{w_i (\Sigma w)_i}{\sigma_p} - \frac{1}{n} \right)^2$$

**코드 대응** (`get_risk_parity_weights`, 358~411行):
```python
def calc_risk_contribution(weights):
    port_vol = np.sqrt(np.dot(weights.T, np.dot(cov_array, weights)))
    marginal_contrib = np.dot(cov_array, weights)          # Σw
    return np.multiply(marginal_contrib, weights) / port_vol   # RC_i
def objective(weights):
    risk_contrib = calc_risk_contribution(weights)
    target_risk = 1.0 / n
    return np.sum((risk_contrib - target_risk) ** 2)
```

> 참고 1: 원본 코드는 목적함수 그래디언트를 **수치미분(중앙차분)** 으로 구합니다(383行). RC의 해석적 미분이 복잡하기 때문이며, "미분이 어려우면 수치미분"이라는 실무 선택을 보여줍니다.
>
> 참고 2 (스케일 이슈): 원본 코드는 정규화 전 위험기여도($RC_i$, 합계 $=\sigma_p$)를 목표 $1/n$과 비교합니다. $\sigma_p \neq 1$이므로 목표와 스케일이 어긋납니다. 동봉된 교육용 스크립트(`portfolio_models_edu.py`)는 이를 **퍼센트 위험기여도** $PRC_i = RC_i/\sigma_p$ (합계 $=1$)로 정규화한 뒤 $1/n$과 비교하도록 교정했습니다. 그 결과 위험기여도가 실제로 $1/n$에 수렴합니다. → "목적함수의 스케일을 맞춰야 한다"는 좋은 교육 사례.

## 7. 4대 모델 비교표

| 항목 | Equal-Weight | GMV | MDP | Risk Parity |
|---|---|---|---|---|
| **한글명** | 동일가중 | 최소분산 | 최대분산투자 | 위험균등 |
| **목적함수** | — | $\min w^T\Sigma w$ | $\max \dfrac{w^T\sigma}{\sigma_p}$ | $\min \sum(RC_i - \tfrac1n)^2$ |
| **기대수익률 사용?** | ✗ | ✗ | ✗ | ✗ |
| **공분산 사용?** | ✗ | ✓ (전체 Σ) | ✓ (전체 Σ) | ✓ (전체 Σ) |
| **개별 변동성 σᵢ 사용?** | ✗ | (대각) | ✓ (명시적) | (대각) |
| **핵심 철학** | 무정보/균등 | 위험 최소화 | 분산효과 최대화 | 위험 균등분배 |
| **집중 경향** | 없음 | 저변동성 종목 쏠림 | 저상관 종목 쏠림 | 완만한 분산 |
| **그래디언트** | — | 해석적 $2\Sigma w$ | 해석적 | 수치미분 |
| **대표 문헌** | DeMiguel(2009) | Markowitz(1952) | Choueifaty(2008) | Maillard(2010) |

## 8. 수치최적화: 투영 경사하강법

세 모델(GMV/MDP/RP)은 **동일한 최적화 엔진**을 공유합니다. 코드에서는 `grg_optimize`로 명명(GRG = Generalized Reduced Gradient 스타일).

### 알고리즘
```
초기값 x0 (랜덤) 부여
반복:
  1. grad = gradient(w)                # 경사 계산
  2. w = w - learning_rate * grad      # 하강 스텝
  3. w = project_weights(w, l, u)      # 제약조건으로 투영 (clip + 정규화)
  4. learning_rate *= 0.999            # 학습률 점진 감소
  수렴하면 종료
30회 랜덤 재시작(multi-start) → 최적값 채택
```

### 제약조건 투영 (`project_weights`, 30~42行)
```python
weights = np.clip(weights, lower, upper)   # 상·하한 강제
weights = weights / np.sum(weights)        # 합계=1로 정규화
```

### 동적 제약조건 (36~38行)
$$l = \max\!\left(0.01,\ \frac{0.5}{n}\right), \qquad u = \min\!\left(0.40,\ \frac{3.0}{n}\right)$$
→ 종목 수에 따라 최소/최대 비중을 자동 조정 (균등배분 대비 50%~300%).

**교육 포인트**:
- **Multi-start**: 목적함수가 비볼록(특히 MDP, RP)일 수 있어 지역해 회피용으로 30회 재시작.
- **투영법(projection)**: 라그랑주 승수/QP 솔버 대신 "일단 이동 후 제약으로 되돌리기". 직관적이지만 근사적.

## 11. 토론거리 및 흔한 함정

원본 코드를 "정답"이 아니라 **비평적으로** 다루면 교육 효과가 큽니다.

1. **샤프비율의 무위험이자율 생략** (742行): $Sharpe = R/\sigma$로 $r_f=0$을 가정. 정확한 정의는 $(R - r_f)/\sigma$. 금리가 높은 시기엔 왜곡.

2. **인샘플(In-sample) 최적화**: 같은 기간으로 최적화하고 평가 → 과적합. 실전에서는 **워크포워드(walk-forward)** 백테스트 필요.

3. **제약조건 투영의 근사성**: `clip → normalize`는 진짜 제약최적화의 KKT 해와 다를 수 있음. → cvxpy 등 QP 솔버와 비교하면 좋은 심화 주제.

4. **공분산 추정의 불안정성**: 표본 공분산 $\Sigma$는 종목 수가 많으면 특이(singular)에 가까워짐 → Ledoit-Wolf 축소추정(shrinkage) 소개.

5. **252일 연환산의 신뢰성**: 데이터가 30일뿐이어도 연환산 → 통계적 의미 약함.

6. **거래비용·리밸런싱 미반영**: 이론 비중과 실현 성과의 괴리.
